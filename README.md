### 📌 Project Overview
An end-to-end data analytics workflow designed to track business sales and profitability across multiple regions and product categories:

- **Data Processing (Python & Excel):** Data cleaning, null handling, and metric validation using Pandas and Excel.
- **Database Management (SQL):** Schema design, transactional data querying, and aggregations.
- **Business Intelligence (Power BI Desktop):** 
  - Executive KPI cards (Sales, Profit, Profit Margin).
  - Time-series Monthly Sales Trend and Regional Profit distribution.
  - Interactive multi-parameter filtering using Product, Month slider, and Year tile slicers.
